BaomauConnect là một ứng dụng web SPA nhẹ giúp kết nối giữa bảo mẫu và phụ huynh theo thời gian thực. Hệ thống thu thập thông tin từ cả hai phía, đồng bộ dữ liệu lên Google Sheets thông qua Google Apps Script và cung cấp giao diện quản trị để xem, chỉnh sửa và xóa hồ sơ.

## Tính năng
- Biểu mẫu riêng cho bảo mẫu và phụ huynh
- Tự động chọn địa chỉ theo tỉnh/thành, quận/huyện, xã/phường
- Hỗ trợ khai báo khung giờ làm việc và mức lương
- Đồng bộ dữ liệu tự động với Google Sheets
- Bảng điều khiển quản trị để quản lý dữ liệu

## Công nghệ sử dụng
- Frontend: HTML, CSS, JavaScript
- UI: Font Awesome, SweetAlert2
- Backend/API: Google Apps Script + Google Sheets
- Bảo mật: CryptoJS

## Cấu trúc dự án
- index.html: giao diện người dùng
- admin.html: giao diện quản trị

## Hướng dẫn sử dụng
1. Mở file index.html để nhập thông tin.
2. Cấu hình URL Google Apps Script trong file JavaScript.
3. Truy cập admin.html để quản lý dữ liệu.
